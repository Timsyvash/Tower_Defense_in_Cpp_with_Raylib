# 🛡️ Cyber Tower Defense

A classic **Tower Defense** strategy game built in C++ using the **Raylib** library. Defend the cyber grid from incoming waves of digital threats, build and upgrade specialized towers, and conquer multiple levels!

---

## 🎮 Features

* **Three Tower Types:**
  * **Standard Tower (100G):** Balanced range and firing rate.
  * **Sniper Tower (175G):** Long range, high damage, slower attack.
  * **Cryo Tower (150G):** Slows down enemies to give other towers more time.
* **Progression & Upgrades:** Towers gain experience (kills) and level up automatically, increasing their range and fire rate.
* **Challenging Waves & Bosses:** Face regular enemies, fast variants, and heavy bosses that trigger screen flashes upon spawning.
* **Multiple Levels:** Progress through different winding paths and defeat all waves to achieve victory.
* **Audio & Visuals:** Cyberpunk-inspired grid aesthetic, sound effects, and interactive UI.

---

## ⌨️ Controls

* **[1-3]** — Select tower type to build
* **[Left Click]** — Build selected tower (on valid grid space off the path)
* **[Right Click]** — Sell tower (recovers gold)
* **[SPACE]** — Start next wave
* **[ENTER]** — Start game from main menu
* **[R]** — Restart game after Game Over or Victory

---

## 🛠️ Built With

* **C++** — Core game logic
* **Raylib** — Graphics rendering, window management, and audio
